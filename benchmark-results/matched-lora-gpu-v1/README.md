# 같은 데이터로 학습한 Qwen과 EXAONE 비교

두 백본에 학습 138건, 138스텝, 평가 54건, 시드 42, LoRA rank 8, alpha 16, 학습률 0.0003, q_proj·v_proj를 사용했다. EXAONE 원본 리비전은 `3abf2810673c7c0778df64a73c2d52eab32d91c4`다. Qwen은 같은 설정으로 앞서 학습한 어댑터와 동일 입력에서 얻은 Intel Arc 결과를 재사용했다. 생성은 Q4_K_M 기반과 F16 LoRA를 사용했고, Vulkan 로그에서 Qwen 29/29, EXAONE 31/31 레이어가 Intel Arc에 배치된 것을 확인했다.

| 지표 | Qwen3-0.6B + LoRA | EXAONE 4.0 1.2B + LoRA |
|---|---:|---:|
| 가중치와 LoRA | 약 487 MB | 약 816 MB |
| 정수의 역할에 맞는 값 | 2/4 | 3/4 |
| 안내의 활동·수치·의미 일치, 새 사실 없음 | 3/8 | 6/8 |
| 위 기준을 충족한 한국어 안내 | 0/4 | 2/4 |
| 안내 8건 경과 시간 | 22.43초 | 41.89초 |
| 전체 12개 요청의 평균 시간 | 2.87초 | 6.18초 |

내용은 출력 원문을 읽어 판정했다. 위 안내 지표는 사실 기준이며 한 문장 여부를 별도로 본다. 더 엄격하게 내용과 완결된 한 문장을 함께 요구하면 Qwen 2/8, EXAONE 3/8이다. EXAONE은 한국어 체육 안내 두 건을 완결된 문장으로 썼지만, 한국어 토성 관측 요청에 영어로 답했다. 달 관측 안내에서는 원문에 없는 관측 조건을 덧붙였다.

시간에는 호출마다 발생하는 모델 로딩이 포함된다. 사실 기준을 통과한 안내 처리량은 Qwen 약 0.13건/초, EXAONE 약 0.14건/초다. 이 차이는 작은 표본과 서로 다른 실행 시점에서 측정했으므로, 처리량 우위를 판단하려면 같은 세션에서 모델을 한 번 로드하고 더 많은 사례를 비교해야 한다.
