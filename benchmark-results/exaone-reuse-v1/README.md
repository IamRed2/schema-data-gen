# EXAONE GPU 모델 재사용 실험

Intel Arc에서 EXAONE 4.0 1.2B Q4_K_M과 같은 상황 학습 LoRA를 사용했다. `llama-server` 작업 프로세스를 한 번 실행했고 GPU 레이어 31/31을 확인했다. 첫 로딩과 준비에는 1.19초가 걸렸다.

| 같은 안내 요청 8건 | 호출마다 모델 로드 | 한 번 로드 후 재사용 |
|---|---:|---:|
| 전체 경과 시간 | 41.89초 | 9.20초 |
| 모델 준비 이후 요청 시간 합계 | 매 요청에 로딩 포함 | 8.01초 |
| 활동명과 정원·시각의 의미가 맞는 안내 | 6/8 | 6/8 |

기존 열은 [이전 Intel Arc 결과](../matched-lora-gpu-v1/results.json)를 사용했다. 두 경로는 같은 입력과 시드 및 가중치를 사용했으며, 채팅 렌더링과 프롬프트 재사용을 담당하는 실행기가 달라 생성 문장도 달라졌다. 6/8은 한 문장 여부와 별개로 활동과 수치의 의미를 읽어 판정한 결과다.

한국어 네 상황을 번갈아 사용한 부하 테스트에서는 Python이 활동명과 세부값을 채우고 모델이 안내문을 생성했다. 100건 모두 스키마를 통과했고, 작업 프로세스 준비 후 55.46초가 걸렸다. 활동명·숫자·관련 표현의 문자 규칙을 97건이 통과했다. 이 자동 점수는 정원을 실제 참가 인원처럼 쓰거나 시작 시각을 종료 시각처럼 쓰는 오류까지 판별하지 못한다. 네 상황을 반복한 실험이므로 여러 복합 스키마의 실제 처리량은 별도로 측정해야 한다.
