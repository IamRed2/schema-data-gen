# 백본 비교 1차 결과

같은 Windows CPU 실행기에서 LoRA를 적용하지 않은 Qwen3-0.6B와 Qwen3.5-0.8B를 비교했다. 스키마 4개 × 출력 언어 2개 × 조합당 4건이며 시드는 42다. 두 모델의 샘플 64건과 실행별 지표는 [summary.json](summary.json)에 연결돼 있다.

| 지표 | Qwen3-0.6B | Qwen3.5-0.8B |
|---|---:|---:|
| 가중치 크기 | 484.2 MB | 541.9 MB |
| 유효 레코드 | 32/32 | 32/32 |
| 누적 경과 시간 | 51.0초 | 106.4초 |
| 초당 유효 레코드 | 0.627 | 0.301 |
| 같은 실행 내 완전 중복 | 14/32 | 6/32 |

시간에는 각 실행의 모델 로딩과 검증이 포함된다. 중복은 동일한 레코드가 같은 실행에 두 번째부터 나타난 건수를 합산했다.

## 샘플 관찰

- **한국어 고객 문의**에서 0.8B가 4건 모두 영어로 출력했다. 0.6B는 주로 한국어를 사용했지만 일부는 상담원 말투이거나 한자가 섞였다. [0.8B 샘플](candidate-support-request-ko.json) · [0.6B 샘플](baseline-support-request-ko.json)
- **한국어 점검 안내**에서 0.8B는 구체적인 날짜와 시각을 넣었지만 실제 공지 대신 공지 작성 방법을 설명하는 문장이 나왔다. 0.6B도 점검 시각과 대안이 빠진 채 설명을 되풀이했다. [0.8B 샘플](candidate-maintenance-notice-ko.json) · [0.6B 샘플](baseline-maintenance-notice-ko.json)
- **영어 수리 요청**에서 0.8B는 시설별 고장 상황을 썼지만, 입주자의 직접 요청 대신 건물 관리자의 행동을 제3자 시점으로 설명했다. [0.8B 샘플](candidate-maintenance-request-en.json)

이번 표본에서 0.8B의 중복 건수는 줄었지만 한국어와 작성자 역할을 안정적으로 따르지는 못했다. 처리량과 언어 오류를 고려하면 현재 기본 모델을 유지할 근거가 있다. 모델을 바꾸기 전에 같은 필드명에서 역할과 출력 언어를 교차한 학습 쌍을 보강한 뒤 다시 비교할 수 있다.
