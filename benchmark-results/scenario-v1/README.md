# 전체 상황 입력 비교

Qwen3-0.6B에 138건으로 학습한 값 단위 LoRA를 사용했다. 전체 평가 54건의 평균 토큰 손실은 1.6355였다. 생성 비교에는 학습에 사용하지 않은 관측 프로그램과 실내 체육 활동에서 한국어·영어 제목 8건, 안내문 8건을 사용했다. 두 조건에서 모델, 시드, 필드 설명을 공유했다. 상황 입력을 생략한 조건에서 동일해진 요청은 이전 출력을 재사용했다.

| 항목 | 필드 설명만 | 전체 상황 포함 |
|---|---:|---:|
| 문자열 제약 통과 | 16/16 | 16/16 |
| 제목에 핵심 활동 반영 | 0/8 | 5/8 |
| 안내문에 핵심 활동과 정확한 수치 또는 시각 포함 | 0/8 | 0/8 |

내용 점수는 출력 원문을 읽어 판정했다. 영어 제목 `Saturn`과 한국어 제목 `배드민턴 라켓`은 핵심 활동을 알아볼 수 있어 제목 항목에 포함했지만 그대로 쓰기에는 덜 구체적이었다. 관측 안내에서는 정원 대신 입구의 물 판매 정보를 반복한 사례가 있었다. 체육 안내에서도 시작 시각과 무관한 내용이 나왔다.

이 비교는 같은 어댑터에 상황을 전달하는 효과를 본다. 이전 어댑터 대비 학습 효과와 전체 레코드 처리량은 별도 비교가 필요하다.
