# 타입 추론과 값의 역할 평가

현재 Qwen3-0.6B와 상황 학습 LoRA를 사용했다. 각 요청을 같은 고정 시드로 한 번 실행했다. 타입 추론은 필드명과 설명으로 타입 이름을 출력하게 하고, 값 평가에서는 스키마 타입과 여러 수치가 포함된 상황을 제공했다. 타입 추론은 평가 코드에서만 실행했다.

| 지표 | 정답 |
|---|---:|
| 정확한 타입 이름 | 4/8 |
| 같은 필드명의 두 설명에 모두 맞는 타입 | 1/4쌍 |
| 정수의 역할에 맞는 값 | 2/4 |
| 같은 상황에서 두 역할 모두 맞는 값 | 0/2쌍 |

`available`은 설명에 따라 boolean과 array를 구분했다. `capacity`는 두 설명에서 string이 나왔다. 정수 생성은 4건 모두 파싱됐지만 최대 수용 인원과 현재 예약자 수가 모두 28, 주문 수량과 발송 수량이 모두 21로 나왔다. 이 실행은 기존 모델의 기준 결과다. 타입 추론 보조 학습의 효과는 새 예제로 학습한 뒤 같은 평가에서 비교할 수 있다.
