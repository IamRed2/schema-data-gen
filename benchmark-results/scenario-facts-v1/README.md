# 전체 상황과 필드별 필수 사실 비교

이전 평가의 관측·체육 안내문 8건을 사용했다. 같은 Qwen3-0.6B, 상황 학습 LoRA, 필드 설명, 상황, 시드로 생성하면서 새 조건에는 활동명과 정확한 정원 또는 시작 시각을 `plan`의 두 항목으로 추가했다. 필수 사실은 평가 입력에서 사람이 지정했다.

| 지표 | 상황만 | 상황과 필수 사실 |
|---|---:|---:|
| 문자열 스키마 통과 | 8/8 | 8/8 |
| 활동과 정확한 정원·시각을 올바른 의미로 전달 | 0/8 | 3/8 |
| 위 조건을 충족한 한국어 안내 | 0/4 | 0/4 |
| 위 조건을 충족한 영어 안내 | 0/4 | 3/4 |

사람이 문장을 읽어 활동, 수치, 수치의 의미를 확인했다. 영어 달·토성 관측과 탁구 안내가 통과했다. 한국어 토성 안내는 24를 언급했으나 정원을 실제 참가자 수처럼 표현했다. 한국어 체육 안내 두 건은 시각을 빠뜨렸다. 영어 배드민턴 안내는 입력 지시문을 복사했다.

이 결과는 필수 사실을 전달했을 때의 소규모 비교다. 스키마를 읽고 필수 사실을 자동 선정하는 단계와 전체 레코드 처리량은 측정하지 않았다.
