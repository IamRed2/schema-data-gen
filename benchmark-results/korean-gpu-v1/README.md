# Intel Arc에서 Qwen과 EXAONE 비교

Intel Arc Graphics의 Vulkan0에서 llama.cpp b12502 Vulkan 실행기를 사용했다. 36개 공통 비교 호출 모두 모델 레이어 전체를 GPU에 배치했다. Qwen은 29/29, EXAONE은 31/31이었다. 모델마다 같은 시드와 입력으로 정수의 역할 구분 4건, 한국어·영어 안내문 8건을 비교했다.

| 지표 | Qwen3-0.6B 기본 | Qwen3-0.6B + 상황 LoRA | EXAONE 4.0 1.2B 기본 |
|---|---:|---:|---:|
| 가중치 크기 | 484 MB | 487 MB | 812 MB |
| 정수의 역할에 맞는 값 | 0/4 | 2/4 | 1/4 |
| 활동과 정확한 정원·시각을 맞게 전달한 안내 | 0/8 | 3/8 | 0/8 |
| 호출 평균 시간 | 4.14초 | 2.87초 | 3.18초 |

안내문은 사람이 활동과 수치의 의미를 읽어 판정했다. Qwen LoRA의 통과 3건은 모두 영어였으며, 그중 탁구 안내는 사실을 포함한 짧은 구절이었다. 시간에는 매 호출의 실행기 시작, 모델 로딩 및 생성이 들어간다. 생성 길이가 달라 GPU의 순수 연산 속도를 이 수치로 비교하기 어렵다.

두 기본 모델에 동일한 자연어 입력을 준 추가 비교에서도 모든 호출의 GPU 배치를 확인했다. EXAONE의 영어 탁구 안내 한 건은 활동과 시각을 담은 짧은 구절이었다. 두 모델의 한국어 안내는 모두 내용 기준에 미달했다.

| 자연어 입력 지표 | Qwen3-0.6B 기본 | EXAONE 4.0 1.2B 기본 |
|---|---:|---:|
| 정수의 역할에 맞는 값 | 0/4 | 2/4 |
| 활동과 정확한 정원·시각을 맞게 전달한 안내 | 0/8 | 1/8 |
| 호출 평균 시간 | 2.79초 | 4.68초 |

백본 비교에서는 두 기본 모델을 비교한다. EXAONE은 이 표본에서 역할 구분에서 앞섰고, 한국어 안내는 두 기본 모델 모두 0/4였다. Qwen LoRA의 결과는 현재 사용 가능한 학습 모델을 확인하기 위한 참고값이다. 같은 데이터로 양쪽을 미세조정했을 때의 성능은 비교하지 않았다.
