# 자연어 필드 생성 백본 비교

프로젝트 LoRA 없이 세 모델을 동일한 Vulkan llama-server로 Intel Arc에서 실행했다. 한 모델을 한 번 로드한 뒤 한국어 6건과 영어 6건을 처리했다. 각 언어는 고객 문의, 상담원 답변, 행사 안내, 상품 소개, 장애 제목, 인명을 포함한다. 모든 요청의 시드는 42다.

현행 JSON 프롬프트와 자연어 프롬프트에서 필드명, 설명, 관련 사실을 동일하게 제공했다. 두 경로에 동일한 JSON 문자열 출력 제약을 적용했다. 자연어 경로는 사용자 메시지 하나로 구성하고 `/no_think` 접미사를 생략했다. 따라서 이 비교는 프롬프트 구성 전체의 차이를 측정한다.

| 모델 | GGUF | GPU 레이어 | 현행 요청 합계 | 자연어 요청 합계 | 바로 쓸 수 있는 값, 현행 / 자연어 |
|---|---:|---:|---:|---:|---:|
| EXAONE 4.0 1.2B | 812 MB | 31/31 | 11.46초 | 15.06초 | 0/12 · 0/12 |
| Gemma 3 1B IT | 806 MB | 27/27 | 18.56초 | 22.16초 | 1/12 · 3/12 |
| Qwen3.5 0.8B | 542 MB | 26/26 | 15.19초 | 16.51초 | 3/12 · 0/12 |

요청 시간 합계에서 모델 시작 시간은 제외했다. 실행별 시작 시간은 원본 결과에 있다. 전 모델·프롬프트의 72개 값은 문자열 타입과 길이 제약을 통과했다.

출력 언어, 필드의 용도와 작성자 역할, 요구한 사실을 충족하고 설명 복제나 필드 라벨 없이 그대로 저장할 수 있는지를 사람이 판정했다. 통과한 사례는 현행 Gemma의 영어 인명, 현행 Qwen의 영어 행사 안내·장애 제목·인명, 자연어 Gemma의 한국어 인명·영어 인명·영어 상품 소개다. 예를 들어 자연어 Gemma는 한국어 행사 정원 18명 대신 현재 예약자 수 11만 반환했다. Qwen은 현행 영어 행사 안내에서 정원 14명과 시작 시각 오전 10시를 반영했다.

표본은 언어별 6건과 시드 하나다. 비교에 사용한 모델은 배포된 지시 학습 체크포인트이며 프로젝트 미세조정은 적용하지 않았다. 자연어 경로가 더 나았던 것은 Gemma의 이번 표본이다. 현재 EXAONE LoRA를 교체할 근거는 이 비교에서 확보되지 않았다.
