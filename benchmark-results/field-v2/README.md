# 필드 단위 생성 비교

Qwen3-0.6B 4비트 모델 하나로 단어·짧은 제목·문장 스키마를 각각 한국어와 영어로 실행했다. 조합당 4건, 시드 42이며 LoRA는 사용하지 않았다. 두 방식 모두 실행 시간에 모델 로딩과 원본 스키마 검증이 포함된다.

| 지표 | 레코드 전체 | 필드 단위 |
|---|---:|---:|
| 스키마 유효 레코드 | 24/24 | 24/24 |
| 누적 경과 시간 | 25.221초 | 21.061초 |
| 초당 유효 레코드 | 0.952 | 1.140 |
| 같은 실행 내 완전 중복 | 3 | 1 |

필드 단위 생성은 이 표본에서 처리량이 약 20% 높았다. 영어 물품 상태에서 주방 식탁의 다리가 휘었다는 구체적 문장을 만든 사례가 있었다. 일부 행은 주방과 야외 범주를 뒤바꿨다. 영어 물품명에서는 범주 코드 `kitchen`·`outdoor`를 출력했고, 한국어 상태 문장에서는 프롬프트의 연필 예시를 그대로 가져온 사례가 있었다. 설명에 맞는 값의 정확성과 자연스러움에는 추가 개선이 필요해 기본 실행은 레코드 전체 방식으로 두었다.
